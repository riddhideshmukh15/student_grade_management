# 🎓 Student Grade Management System

A simple Python-based Student Grade Management System that allows users to manage student records from the command line. This project demonstrates the use of Python dictionaries, functions, loops, conditional statements, and user input.

## 🚀 Features

* ➕ Add a new student with grades
* ✏️ Update an existing student's grades
* 🗑️ Delete a student record
* 📋 View all student records
* 🔍 Search for a student by name
* 🚪 Exit the program safely
* ✅ Handles invalid menu input
* ✅ Case-insensitive student search (e.g., `Disha`, `disha`, `DISHA`)

## 🛠️ Technologies Used

* Python 3
